# 04 · 面试准备报告：结构与流程

> 一场 60 分钟的面试，准备量大概是 6–10 小时。这个文件的作用是**让这 6 小时花在能被问到的地方**。

---

## 一、九个阶段

```
① 读公司文件    年报 / 招股书 / 公告 / 官网 → 事实底稿
② 外部检索      近 3 个月动态、行业趋势、岗位挂牌价
③ 竞品对标      业务竞争 + 组织机制 两个维度
④ 方案融合      你有思路就以你的为骨架；没有就先出 2–3 个方向
⑤ 写成报告      按下面第五节的结构
⑥ 岗位关联      每条信息都要回答"这对这个岗位意味着什么"
⑦ 问答准备      预判 8 个以上高频问题
⑧ 精炼          压成一页提词器
⑨ JD 映射       逐条对证据（见 03-jd-mapping.md）
```

**顺序不能跳。** 常见错误是先写"自我介绍"，再回头找材料——那样写出来的是自我评价，不是研究。

---

## 二、读公司文件：只读四类地方

年报动辄 200–300 页，逐页读是浪费。按这四类定位：

| 读什么 | 为什么 |
|---|---|
| 董事长/CEO 致辞 | 战略方向、文化基调，面试官常引用 |
| 业务回顾 / 管理层讨论 | 各板块营收与增速，判断钱从哪来 |
| 与岗位相关的业务板块 | 你要去的部门在大盘里的位置 |
| 人力/治理章节 | 员工规模、结构、激励计划、薪酬政策 |

再补三类"硬数据"：

- 五年财务趋势（营收/利润/毛利率）
- 人均指标（人均营收、人均利润、人事费用率）——**这是专业岗最有力的一手论据**
- 近一期"应付职工薪酬"附注（本期增加额 ≈ 全年人力成本总盘）

> 计算类数据一律标注"基于公开数据测算"。面试官不要求你精确，要求你**有量级感**。

---

## 三、外部检索：六个方向

1. 公司近 3 个月动态（新闻、公告、人事变动、投产/扩产）
2. 行业宏观（规模、增速、政策）
3. 目标岗位的**在招 JD 与挂牌薪资区间**（猎聘/BOSS/智联搜"公司名 + 岗位名"）——挂牌区间是谈薪的第一个锚点
4. 公司高管公开讲话 / 内部信（"降本增效""聚焦主业"这类词是信号）
5. 公司的数字化 / AI 动作（搜"公司名 + 数字化 / 智能化 / 智能体"）
6. 同行同岗位的薪酬基准（分城市、分层级）

**越新鲜的事件越值钱。** 面试前一週发生的组织调整，比三年前的荣誉更有谈资。

---

## 四、竞品对标：两个维度

| 维度 | 回答什么问题 | 输出形式 |
|---|---|---|
| 业务竞争 | "你了解我们的竞争对手吗" | 每家竞品：核心数据 + 优劣势 + 对目标公司的启示 + 一句话话术 |
| 组织机制 | "你打算怎么做" | 竞品的机制创新案例：公司 + 时间 + 机制 + 关键数字 + 你能借用什么 |

选 2–3 家：直接竞对 1 家、区域/模式相似 1 家、转型标杆 1 家。

**能算就算人效对比。** "竞品人均创利 3 万，目标公司 20 万"——这类数字一出口，专业性就成立了。

---

## 五、报告结构

按这个顺序写（可根据信息丰富度增减，但顺序别乱）：

| # | 章节 | 内容 |
|---|---|---|
| 1 | **一页速览** | 终面前最该记住的 10–13 条事实，每条标"对岗位的意义" |
| 2 | 公司基本面 | 股权/控制链、业务板块、与岗位相关的实体 |
| 3 | 最新动态时间线 | 近 1–3 个月事件，按时间排，每条配"面试怎么用" |
| 4 | 关键人物 | 汇报线人物、分管领导背景（尤其是同职能出身的） |
| 5 | 业务与财务 | 与岗位相关的业务硬数据、人效指标 |
| 6 | 竞品对标 | 业务 + 机制双维度 |
| 7 | 核心方案 | 你的方案：目标、路径、指标、节奏 |
| 8 | 自我介绍 | 30 秒版 / 2 分钟版 |
| 9 | 问答准备 | ≥8 个问题，每个：观点 → 数据 → 方案 → 与公司的连接 |
| 10 | 90 天计划 | 诊断 → 设计 → 试点 → 推广 → 迭代 |
| 11 | 谈薪备忘 | 挂牌区间、市场基准、报价策略、底线 |
| 12 | 来源列表 | 每个数据可回溯 |

### 两条写作约定

- **每章开头一行速览**：`> 本章速览：一句话核心 + 什么时候用`。终面前只读速览就够。
- **话术用引用块**，与正文区分；话术必须口语化，控制在 30 秒–1 分钟的表达量。

---

## 六、岗位关联：贯穿全程的一条线

写每一条信息时问一句"**这对我要去的岗位意味着什么**"：

| 信息 | 关联到 |
|---|---|
| 财务数据 | 人力预算空间 / 招聘编制 |
| 战略方向 | 考核指标怎么设 |
| 组织变动 | 汇报线、协作关系 |
| 行业趋势 | 人才竞争、用工模式 |
| 新品/新业务 | 新团队怎么搭 |
| 竞品动作 | 你的方案的差异化 |

**没有关联的信息不要写进报告**——它只会稀释重点。

---

## 七、问答准备：8 个必答

1. 你了解我们公司吗？（考研究深度）
2. 你为什么离开上一家？（考稳定性与动机）
3. 这个岗位你打算怎么做？（考方案）
4. 你最大的失败是什么？（考反思）
5. 你和直属领导意见不一致怎么办？（考协作）
6. 你未来 3 年的规划？（考匹配）
7. 你期望薪资？（考锚点）
8. 你有什么问题问我们？（考准备度）

每个答案的结构：**观点 → 数据支撑 → 具体做法 → 与这家公司的连接**。

---

## 八、精炼：一页提词器

报告写完不算完，最后压成一页：

```
定位（一句话）：
三个必须让对方记住的点：1) __ 2) __ 3) __
三个必须问对方的问题：1) __ 2) __ 3) __
三条避雷：1) __ 2) __ 3) __
```

面试当天只看这一页。

---

## 九、常见坑

- **数据编造**：查不到就写"未披露"，不要猜。面试官一句追问就穿。
- **竞品泛泛而谈**：要具体到"哪家公司、什么时候、做了什么、效果如何"。
- **话术太长**：每个回答控制在 1 分钟内，超过就是背稿。
- **简历口径不一致**：报告里对某段经历的说法，必须和简历一致；不同说法要提前统一。
- **只准备"我做过什么"，不准备"为什么这么做"**：后者才是判断力的证据。
