# 02 · 公司与岗位评估表

> 目标：把"这家看着还行"变成**可比较的分数**。人一次只能记住 7±2 个选项，而一周可能看到 40 个岗位——不打分就等于随机选。

---

## 一、先定硬门槛（不满足直接淘汰）

硬门槛是"无论其他多好都不看"的条件，写下来能省掉 80% 的判断时间。常见的几条：

- 通勤/搬迁：能否接受（超出某距离 = 淘汰）
- 用工性质：外包 / 劳务派遣 / 驻场 = 淘汰（除非岗位本身在甲方）
- 公司状态：经营异常、涉诉多、连续亏损 = 淘汰
- 岗位性质：纯执行岗 vs 能独立负责一块 = 按你的阶段定

> 门槛要写**具体**。"看发展"不是门槛，"是否要求独立负责一个模块"才是。

---

## 二、五维评分（满分 100）

| 维度 | 权重 | 评分要点 |
|---|---|---|
| **地域匹配** | 20 | 目标城市 20；周边可接受 12；需搬迁 5；异地且不愿搬 0 |
| **公司成色** | 25 | 上市主体/集团总部 25；集团分公司/新基地 22；区域龙头 15；本地小公司 3 |
| **岗位内容** | 25 | 独立负责一块 + 从 0 到 1 25；多模块统筹 18；单模块 10；纯执行 3 |
| **薪资匹配** | 20 | 达到目标区间上限 20；区间内 16；略低但有结构（年终/补贴）8；明显低于底线 0 |
| **阶段红利** | 10 | 新基地/新项目/扩产期 10；成长期 6；成熟稳定 3；收缩期 0 |

**判定**

| 分数 | 处置 |
|---|---|
| ≥ 75 | 推荐：进候选清单，写推荐理由 |
| 60–74 | 备选：列出但不主推 |
| < 60 | 淘汰：不出现 |

## 三、权重必须按你的情况改

上面这套权重是为"换平台、要更大责任范围"的人设调的。三类常见人设应该换权重：

| 你的处境 | 建议调整 |
|---|---|
| 刚毕业 / 转行，先要入场 | 岗位内容降到 15，公司成色降到 15，**成长性/带教**提到 25（有没有人带、能不能学到东西） |
| 稳定期，不想折腾 | 地域 25、薪资 25、**稳定性**（成立年限/融资/盈利）20 |
| 想搏一把成长 | 阶段红利提到 20、岗位内容提到 30，薪资降到 10 |

改权重的方法：把你最不能妥协的两项加起来放到 45–50 分，剩下的分给其他三项。**权重之和必须是 100**。

## 四、"公司成色"怎么快速判断

不需要查很多资料，公司页的工商信息 + 三条外部检索就够：

| 看什么 | 在哪看 | 判断 |
|---|---|---|
| 企业类型 | 招聘平台公司页的工商信息 | 股份有限公司 / 上市 / 集团 |
| 注册资本 | 同上 | ≥1000 万；实缴比认缴可靠 |
| 股东结构 | 企查查 / 天眼查（免费额度够用） | 有产业资本或上市公司持股 = 加分 |
| 近期动态 | 搜"公司名 + 投产 / 扩产 / 新基地 / 融资" | 近 12 个月有扩张 = 阶段红利 |
| 风险信息 | 搜"公司名 + 欠薪 / 裁员 / 劳动仲裁" | 有集中负面 = 一票否决 |

## 五、岗位内容怎么读 JD

同一句"负责薪酬绩效管理"，可能是三种活：

| 表述 | 实际含义 | 判断 |
|---|---|---|
| "独立负责 XX 体系搭建" | 从 0 到 1，有决策权 | 高价值 |
| "协助完善 XX 制度" | 参与，但不是主导 | 中等 |
| "负责 XX 数据的核算与发放" | 执行，重复劳动 | 低价值 |

判据是**动词 + 宾语 + 权限**：
- 动词：搭建 / 设计 / 优化 > 协助 / 参与 > 执行 / 录入
- 宾语：体系 / 方案 / 机制 > 流程 / 表单 > 数据 / 报表
- 权限：有没有"向谁汇报"和"带几个人"

JD 里没写的，就是面试要问的（见 `03-jd-mapping.md`）。
