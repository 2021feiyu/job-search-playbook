# 01 · 岗位搜索 SOP

> 目标：把"每天刷招聘软件"变成**可复现的检索流程**——同样的条件，任何时候跑，结果一致。

招聘平台的默认设计是"让你多看"，不是"让你找得准"。所以必须自己定参数、自己定顺序，否则一小时翻下来只记得三家公司。

---

## 一、先把条件写成参数

以 BOSS 直聘为例，筛选栏从左到右共 10 个：

```
城市 | 工作区域 | 职位类型 | 求职类型 | 薪资待遇 | 工作经验 | 学历要求 | 公司行业 | 公司规模 | 融资阶段 | 清空
```

真正决定结果质量的只有四个：**城市、薪资、规模、融资阶段**。其余维度用关键词比用筛选器准。

| 维度 | 建议 | 说明 |
|---|---|---|
| 城市 | 先定城市池，再逐城跑 | 不要"全国"搜——同一岗位在不同城市的薪资与要求差异极大 |
| 工作区域 | 只搜主城时跳过 | 下沉到区县会显著改变结果 |
| 职位类型 | 不选 | 分类粒度粗，容易漏 |
| 求职类型 | 全职 | — |
| **薪资** | 按预期上限的下一档选 | 平台按**上限**归档：9–14K 的岗位会出现在 10–20K 档里 |
| 工作经验 | 不选 | 招聘方普遍放宽 |
| 学历 | 不选 | 同上 |
| 公司行业 | 可选 1–2 个 | 选太多会把结果打散 |
| **公司规模** | **单选，两档分两次跑** | 1000–9999 与 10000 以上不能同时选 |
| **融资阶段** | 已上市 / 不需要融资 | 这一项对"公司成色"的筛选效率最高 |

### URL 参数（实测，换城市后其余条件自动保留）

```
/web/geek/jobs?city=<城市码>&salary=405&scale=305&stage=807&query=<关键词>
```

| 参数 | 值 | 含义 |
|---|---|---|
| `salary` | 405 | 10–20K |
| `scale` | 305 | 1000–9999 人 |
| `stage` | 807 | 已上市 |

> 平台会改版，参数以实际页面为准。**不要手改地址栏**——用点击操作，改地址容易触发安全校验。

---

## 二、六步操作

```
① 点【城市】→ 选目标城市（热门城市直接点；其他点字母分类 → 城市名）
② 点【工作区域】→ 选区县（只搜主城就跳过）
③ 点【薪资待遇】→ 目标档位
④ 点【公司规模】→ 1000–9999 人（或 10000 以上，二选一，分两次跑）
⑤ 点【融资阶段】→ 已上市
⑥ 点搜索框 → 输入关键词 → 回车
```

结果页的读法是三层：

| 层 | 看什么 | 目的 |
|---|---|---|
| 列表 | 岗位名 / 公司名 / 地点 / 薪资 | 快速淘汰（3 秒一条） |
| 详情 | JD 全文、公司规模、行业、融资 | 判断岗位内容与公司成色 |
| 公司页 | 点公司名 → 新标签 → 滚到底看【工商信息】 | 验证"是不是真公司" |

公司页必看三项：

| 字段 | 位置 | 判定 |
|---|---|---|
| 企业类型 | 工商信息左上 | 含"上市公司"加分 |
| 注册资本 | 工商信息右下 | ≥1000 万优选（低于 100 万要警惕） |
| 规模 / 融资 | 页头公司名下方标签 | 与筛选器一致说明没虚标 |

## 三、五个实测坑

1. **三个筛选叠加会跑偏**
   同时选「薪资 + 规模 + 已上市」再搜窄关键词，命中太少时平台会**自动放宽匹配**，返回一堆不相关岗位。
   对策：结果页先扫岗位名，不相关直接跳过；整页跑偏就撤掉一个条件重搜。

2. **薪资按上限归档**
   9–14K 会落进 10–20K 档。**判定看下限，不看档位。**

3. **公司规模是单选**
   1000–9999 与 10000 以上不能同时选，必须跑两遍。

4. **点公司名会开新标签**
   浏览器自动化时要重新接管新标签才能读公司页，读完切回列表继续。

5. **坐标点击有偏移**
   优先点 DOM 节点（岗位卡、公司名、按钮），纯坐标点击只用于没有节点的筛选器，且每次点完要截图核对落点。

---

## 四、操作纪律

这些不是"怕被封号"，是**别把账号搞坏**——招聘平台的登录态绑定手机号，掉了要重新扫码，比慢一点贵得多。

1. **只用点击和输入**，不刷新页面、不改地址栏、不直接调页面接口。
2. **不点"立即沟通"、不投简历、不发消息**——筛选阶段只读。
3. 单日不超过 3 个城市；同一关键词翻页不超过 2 页。
4. 出现验证码 / 安全校验，立即停手，等 10 分钟以上。
5. 登录态失效时**不要自动重登**，交本人扫码。
6. **不要用 CDP / debugger 方案接管页面**：招聘平台会检测调试接入，可能直接判定会话异常并踢下线。用浏览器扩展或纯手动。
