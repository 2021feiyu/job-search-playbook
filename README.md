# Job Search Playbook · 求职操作手册

**把找工作当成一个项目来跑：定参数 → 检索 → 打分 → 准备。**

不是"求职技巧合集"，是五份可执行的流程文件：怎么筛岗位、怎么给公司打分、怎么把 JD 拆成证据、怎么写面试准备报告、怎么体检简历。

---

## 为什么需要这个

找工作最常见的三种低效：

| 症状 | 原因 | 这份手册怎么治 |
|---|---|---|
| 每天刷两小时，一周下来只记得三家公司 | 没有参数、没有输出格式 | 固定筛选条件 + 登记表，每轮产出清单 |
| "这家看着还行" | 没有评分标准，凭感觉 | 五维评分表，权重按你的处境调 |
| 面试前熬夜看年报，还是被问住 | 没有把材料关联到岗位 | 报告结构 + 岗位关联原则 + 一页提词器 |

## 怎么用

### 第一遍：定参数（30 分钟，只做一次）

在 `02-screening-rubric.md` 里选一套权重，写下你的四条硬门槛。以后每看到一个岗位，先过门槛再看分。

### 每周：跑一轮检索（1 小时）

按 `01-search-sop.md` 的六步，跑 3 个城市 × 2 个关键词，结果填进 `templates/岗位登记表.csv`。打分 ≥75 的进候选清单。

### 每周：给候选做 JD 映射（每个 20 分钟）

按 `03-jd-mapping.md` 把 JD 拆成三类要求，逐条对证据，标出缺口。这一步做完，面试准备量能砍掉一半。

### 面试前：写报告（每个 4–6 小时）

按 `04-interview-report.md` 的九阶段跑，最后压成一页提词器。

## 边界

- **不代投、不内推、不抓数据**。脚本只拼 URL 参数，页面还是你自己点。
- **不提供"话术模板"**。话术必须从你自己的经历里长出来，抄来的第一句就会被听出来。
- **平台条款自己确认**。各招聘平台对自动化操作有明确限制，本仓库的纪律章节（只读、限频、遇验证码停手）是为了保护你的账号，不是"反检测技巧"。

---

## 数据来源

- 筛选器参数、URL 参数、公司页工商信息位置：2026-10 实测，平台改版后需自行更新（`scripts/boss_url.py --list` 可打印字典）
- 评分模型、报告结构：来自个人求职实践，不是行业标准
- 所有公司案例均为示例，不含真实企业数据
